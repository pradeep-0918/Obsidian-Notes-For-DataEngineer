# 📌 SQL for Data Engineering

> [!abstract] Quick Summary
> SQL is the language used to communicate with relational databases.
> For a Data Engineer, SQL is not just about retrieving data — it is used to **clean, transform, validate, join, aggregate, and prepare data for analytics and pipelines**.
> We will learn SQL from database fundamentals → analytical SQL → ETL → optimization.
