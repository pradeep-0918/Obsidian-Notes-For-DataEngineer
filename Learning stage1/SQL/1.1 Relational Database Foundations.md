# SQL — Introduction

> [!INFO]
> **SQL (Structured Query Language)** is a language designed to allow both technical and non-technical users to **query, manipulate, and transform data** from a relational database.

Due to its **simplicity**, SQL databases provide **safe and scalable storage** for millions of websites and mobile applications.
